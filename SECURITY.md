# Bezpieczeństwo

Jeśli znajdziesz lukę (np. obejście logowania, wyciek danych, wykonanie kodu), **nie opisuj jej publicznie w
zgłoszeniu (Issue)**. Użyj prywatnego zgłoszenia w zakładce *Security → Report a vulnerability* tego repozytorium.

Panel jest przeznaczony do pracy w sieci zaufanej albo za reverse proxy z HTTPS i kontrolą dostępu. Nie wystawiaj
go do internetu po zwykłym HTTP. Szczegóły: `docs/instalacja-docker.md`.

Projekt jest rozwijany bez gwarancji czasu reakcji.
